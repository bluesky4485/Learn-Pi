Learn Pi

Agency 来自模型。Agent 产品 = Model + Harness。

Thesis
“Adapt pi to your workflows, not the other way around.”

模型是司机；Pi 是车。你学的是造车与改装，不是伪造智能。

Start s01 → Official docs earendil-works/pi

Mindshift

Model = agency

感知、推理、行动的能力来自训练，不是 if-else 工作流图。

Harness = environment

Tools · Knowledge · Observation · Action · Permissions。Pi 提供可扩展的编码环境。

Pi = one agent loop + tools(read, write, edit, bash) + sessions / tree / compaction + AGENTS.md context + extensions · skills · themes · packages + multi-provider models (models.json) + interactive | print | JSON | RPC | SDK The model decides. The harness executes. The loop stays constant. Mechanisms change.

Learning path

主线：行动 → 会话与知识 → 扩展 → 集成 → 安全与哲学。

  • s01 Agent Loop — 循环不变量
  • s02 Tools — 四工具 + registerTool
  • s03 Install & Auth — 装起来、登进去
  • s04 Models — 自定义 URL / Key
  • s05 Sessions — 树、分支、恢复
  • s06 Context — AGENTS.md
  • s07 TUI & Themes — 配色非壁纸
  • s08 Extensions — 钩子不改循环
  • s09 Skills — 按需知识
  • s10 Packages — pi install
  • s11 Run Modes — print / RPC / SDK
  • s12 Architecture — monorepo 分层
  • s13 Compaction — 腾出上下文
